Conecta tu repositorio de GitHub para editar la tienda.

Cómo crear el token (una sola vez)
  1. Entra a GitHub → Settings → Fine-grained tokens.
  2. En Repository access elige Only select repositories y marca el repositorio de Lonvi.
  3. En Permissions → Repository permissions, pon Contents en Read and write.
  4. Ponle una fecha de vencimiento, créalo y pégalo aquí.
